# 错事：中国大陆云备份与管理后台路线图

状态：已确定的后续需求；v0.4 首发仍然本地保存，不提供云端入口。

## 开发阶段

- v0.5：微信和手机号登录、账号绑定与注销。
- v0.6：云备份与恢复、客服工单及内容安全审核管理后台。
- v0.7：跨设备增量同步、冲突保护与离线恢复。
- v1.0：完成云端稳定性、权限和合规验收。

## 云备份与登录

明确支持微信登录、手机号验证码登录和账号关联。允许不登录继续本地记录，登录后必须由用户主动选择云备份，未经明确告知与适用授权不上传旧记录。

云端保存数字、简记、日期、历史修改前后文字、操作时间和时区，继续兼容当前记录结构。云备份先解决恢复与可靠性，再增加事件级跨设备同步；版本冲突不能静默覆盖，记录与完整历史都应保留。支持用户查看备份状态、导出、删除云端数据和账号注销。

云基础设施优先选择中国大陆地域，明确备份地域、数据保留期限和删除机制；限制跨境第三方日志或未经评估的数据复制。具体出境义务按实际处理方式与适用规定评估。

## 管理员权限（此前已确认）

**云端正文允许受限的人工读取，用途为客服处理及必要的内容安全审核。** 不允许任何管理员无理由浏览所有人的私人简记；不得宣传为运营者无法读取的端到端加密。

| 角色 | 能做什么 | 权限边界 |
| --- | --- | --- |
| 客服 | 通过与用户相关的工单处理问题 | 仅工单必要范围，不可全库浏览 |
| 内容安全审核员 | 根据明确合法且必要的审核事由处理具体事项 | 需要理由与受限授权，不可任意巡查 |
| 超级管理员 | 管理系统、角色与访问审批 | 默认无正文阅读权，应急权限有限期与审计 |
| 安全审计 | 检查权限与访问历史 | 日志不包含私人正文 |

所有角色落实最小权限和服务端授权。正文阅读需核验事由、用户或记录范围、授权有效期，并记录访问者、时间、目的、审批、结果。禁止无理由批量查询/导出，必要时采用双人审批、多因素认证、异常访问告警。审计日志不能被管理员随意篡改。云端采用 TLS 传输加密、存储加密与密钥管理，但不作运营者绝对不可读的虚假承诺。

## 中国大陆合规前置条件

1. 按小程序和后端实际服务核对个人主体资格、微信认证/服务类目、APP/小程序备案、域名和云服务接入资质；不假设当前个人主体资格必然覆盖未来云端业务。
2. 执行《个人信息保护法》的合法性基础、清晰告知、最小必要、数据主体查询/复制/纠正/删除等义务。私人正文和修改历史可能包含敏感个人信息，按实际内容与目的评估处理要求，不擅自将所有记录当作普通公开文本。
3. 按适用条件评估网络和数据安全制度、数据受托处理合同、安全保护与个人信息保护合规审计。尤其要审查管理员阅读正文的目的、权限、告知方式和留痕。
4. 云备份应有明确的留存与删除策略、账号注销、备份副本清理、安全事件处置和恢复演练。不得把用户内容上传境外云项目或传给不必要的分析服务。
5. 微信授权登录和手机号验证码能力、短信资质及隐私指引以**正式 AppID 与最新平台后台**为准；正式提供相应服务前完成。是否需要内容审核，应依法并结合实际服务性质判断，而不是允许任意查看私密记录。

权威依据：[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)、[工信部 APP 备案通知（包括小程序）](https://www.gov.cn/zhengce/zhengceku/202308/content_6897341.htm)、[个人信息保护合规审计管理办法](https://www.cac.gov.cn/2025-02/14/c_1741233507681519.htm)、[数据跨境流动规定](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)。

数据库角色、认证会话与管理员受限 SQL 读取的落地要求另见 [云服务安全交接](CN_CLOUD_BACKEND_SECURITY_HANDOFF.md)。

详细的服务端协议、同步冲突规则、合规检查项与可运行合同测试见 [云后端技术设计 v0.1](CN_CLOUD_ENGINEERING_SPEC.md)。 后续版本已新增独立 PostgreSQL 数据库迁移、事务仓储及受限审计读取的集成测试（位于 `future/server/`）；该代码没有与小程序连接，也没有上线。

微信身份映射、单会话退出、密钥轮换已有隔离代码与测试，但微信真实 AppID 和服务端部署并未建立；见 [微信登录与会话交接](CN_CLOUD_WECHAT_AUTH_HANDOFF.md)。

## 工程与发布边界

预留独立服务端的数据模型：用户/认证身份、设备、云备份快照、完整记录事件、同步游标、客服工单、审核案件、员工角色、限时授权、审计记录及删除请求。所有接口检查记录所有权、版本与幂等性。不得靠客户端传入的用户 ID 直接获得别人的数据。

**v0.4 仅冻结本地版功能范围；云备份和管理员功能属于明确的后续交付目标，不是首发已完成功能，也不会因 v0.4 的简化而取消。**
