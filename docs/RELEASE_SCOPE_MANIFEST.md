# 错事 · v0.4 首发候选独立范围

> 本分支从 `main` 建立，按文件引入设计 Draft PR #4 里已经通过回归的 v0.4 客户端内容。不是已经批准发行的 RC1 标签。

## 本分支包括

- 当前日期计数、明确 0、撤销、日历/日期历史、可选简记、统计、主题、设置
- 本机存储与完整修改历史；保留微信聊天 JSON 手动导入/导出作为过渡辅助功能，完整聊天文件往返测试不作为首发 P0
- 微信开发者工具自动回归脚本、Chrome H5 回归、跨日期与数据持久化安全测试
- 隐私文案/审核草案、首发核心 C01–C09 真机验收与非阻断 W01–W12 JSON 备份专项、官方 npm 风险追踪及 CI 工件

## 严格不包括

- 独立原生 App 构建（本次仅 H5 与微信小程序）；`future/cloud/`、`future/server/` 以及云认证、云备份、管理员查阅、手机号登录、账号注销、支付、广告或遥测
- 有效的 AppID/AppSecret、手机号/微信主体数据或个人真实错事 JSON
- 已发布小程序和已通过的备案/真机验收结论

## 发布前硬性阻断

1. **微信 iPhone 核心 C01–C09 真实验收**：正常记录、修改历史、简记、统计、本机持久化/离线、长文本/输入/安全区、清空确认；不是 JSON 聊天往返
2. 官方 npm 现有风险按实际攻击面分级并处置，不仅仅是 剩余 19 项受影响包数量不增加
3. 正式 AppID、个人主体、服务类目、名称/图标、备案、隐私保护指引/公开联系方式核实
4. 标记固定候选提交，整套 CI+实机+隐私材料统一验收；产品负责人另行批准才可创建正式 RC/tag/合并或发布

**发布优先级调整**：完整 W01–W12 JSON 恢复测试降为 P2，不再独立卡首发冻结；若已暴露的功能存在真实数据丢失或隐私风险，仍必须修复/关闭有问题入口。下一版云账号、备份/同步及本地历史安全迁移是 P1 正式能力，首发不得宣传已上云或跨设备找回。

源设计/未来云端仍保留在 [Draft PR #4](https://github.com/ysr666/cuoshi/pull/4)，与此发布分支分离。旧 H5 在线站点不受影响。
