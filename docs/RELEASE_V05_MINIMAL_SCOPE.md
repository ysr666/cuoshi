# 错事 v0.5 · 极简首发范围冻结

2026-10-19 决策：**停止新增功能，后续只做上线阻断项、安全修复和真机体验问题。** 本文只约束 v0.5 微信小程序首发；v0.4 历史代码和 Draft PR #5 不改动。

## 用户真正能用的功能

- **每天一个数**：包括尚未记录、明确记录 0、加减、直接输入与撤销（修改必须留痕）。
- **可选几句话**：随手记录、修改或删除简记，完整保留历史旧文；不强制写原因。
- **回看并修改过去**：同一首页通过日期选择器或前后日期导航查看旧记录、完整修改事件及本地时间。没有单独的统计/日历管理页。
- **默认云端自动保存**：完成明确告知和本人微信账号核验后自动同步；异常时明确提示，已验证的同一账号离线记录保留，不允许跨账号混用。暂停/恢复上传只是撤回及重新确认授权的必要操作，不成为主流程。
- **账号与隐私**：清楚展示同步状态、隐私处理、主动注销及注销结果核验。必要安全审计、最小权限及合法个人信息查阅/复制/删除请求渠道必须留存。

## 本次正式不做

- JSON/文件**导出、导入、手动备份、手动恢复**；不因相关旧版代码存在而增加入口。
- 统计汇总、图表、趋势、排行榜、打卡、连续天数、奖惩、情绪打分、AI 分析。
- 提醒通知、订阅消息、推送、短信/手机号登录、独立 App、多终端订阅账号与社交分享。
- 独立的数据管理仪表盘、复杂客服/管理员可视化工作台、其他可选自定义功能。

**不要误删的安全底座**：账号绑定及隔离、服务端确认与幂等队列、完整不可静默覆盖的修改历史、可靠注销、受限后台访问与脱敏审计、必要的隐私告知。法律要求的个人信息查阅/复制义务可以用人工受理渠道履行，**不等于必须增加普通用户的导出按钮**。

## 发布代码硬门槛（已自动化）

`future/miniapp/build.mjs` 只复制所需的源文件、云同步模块和「今天」「设置」两个页面；不把 v0.4 的统计、日历、导入导出文件桥接或冗余原型复制到构建输入。`future/miniapp/check-build.mjs` 对实际微信包执行文件白名单和禁用接口检查，防止未来误将导入导出、手机号与订阅推送打包进去。旧版 v0.4 保持原样且单独执行隔离 CI。

## 上线前仅允许推进的事项

1. 正式小程序主体与 AppID、名称类目、备案及微信后台隐私指引。
2. 中国大陆云环境、合规 HTTPS 域名、独立数据库权限、密钥和访问日志；生产云的保留期限、删除备份周期及安全复核。
3. 微信真实登录、至少两台真机记录/离线/联网/重启/换号/注销全流程测试。
4. 精简后的 **v0.5** 隐私政策、审核资料和平台需提交的图标截图、公开联系方式。
5. 依赖风险分级处置、正式发布候选源码冻结和最终微信审核。

在以上门槛全部通过前，保持 Draft PR #4；不得声称已生产接入或将测试 AppID、虚构后端冒充正式上线。CI 通过只能证明工程合同，不代表微信平台资格及真实服务已完成。
