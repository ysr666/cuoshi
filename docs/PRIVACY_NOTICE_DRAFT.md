# 错事 · 隐私与数据处理说明（首发草案）

> 供公开前用户文案核对及微信审核配置使用。**目前不是已生效或已审核的正式隐私政策。**
>
> 待正式账号注册后填写：个人运营主体【待填】；可公开的联系邮箱【待填】；正式 AppID【待填】；生效日期【待填】；微信平台隐私指引审批状态【待核实】。不得在公开文件中添加身份证号码、住宅地址等私人信息。

## 产品和数据范围

「错事」是用户自己判断、记录和重新理解个人错误的工具。首发版不自动识别对错，不作评分、诊断或公开社交互动。

| 数据 | 取得方式与用途 | 当前保存方式 |
| --- | --- | --- |
| 日期、0–9999 数字、可选简记 | 用户主动记录及查看 | 微信小程序本机存储 |
| 修改前后的数字与文字、操作时间、操作时区、撤销事件 | 保留完整修改历史 | 本机存储；导出时包含在备份内 |
| 尚未提交的简记草稿 | 保留输入，便于恢复 | 独立本机存储，不在正式 JSON 备份内 |
| 纸张/现代主题选择 | 个人外观偏好 | 本机存储 |
| JSON 文件 | 用户主动备份与恢复 | 导出时临时生成；用户选择微信聊天分享、转存后，自行管理聊天和文件副本 |

操作时区作为事件历史字段保存，不用于实时定位或追踪。当前候选代码没有手机号/微信登录、开发者运营的云同步、广告、支付或行为埋点 SDK；不主动读取联系人、相册、定位、麦克风或相机。

## 文件备份的隐私风险

- **导出**：用户点击「导出完整备份」时，应用生成**未加密的明文 JSON**，里面可能包含所有简记、已删除或编辑的旧文字、日期、操作时间和时区。将文件交给微信聊天分享界面后，用户须在所选聊天中确认发送成功，并妥善保存。
- **导入**：用户主动点击「导入备份」，从微信聊天会话选择 JSON 文件。应用会校验文件结构与完整性，显示日期数和历史事件数，经用户再次确认才替换本设备的全部正式记录，并清除未提交草稿。
- 微信聊天中的备份、对方收到的文件、用户自行另存的文件，不会因为删除「错事」本机记录而自动删除。微信聊天的处理方式受微信自身规则与用户选择的接收方影响。
- 由于用户**主动**使用微信聊天分享，不能宣传“无论何时都不通过网络传输”。也不能宣传备份经过加密，因为当前 JSON 是明文。

## 用户可以做什么

- 在「今天」「日历」「日期详情」查看、修改、撤销数字记录，编辑或删除简记；撤销和删除等操作会保留在历史中。
- 从「设置」导出完整 JSON 备份，以便迁移和恢复；未按「留下」的简记草稿不会被导出。
- 在「设置」经过两次确认删除该设备所有正式记录和草稿。此操作不能删除已分享的备份文件。
- 如清理微信数据、卸载、换设备、设备故障且没有有效备份，原始本地记录可能无法恢复。首发版没有运营者云端的找回能力。

## 微信平台和未来变更

用户主动导入/导出时会调用微信的聊天文件选择与分享功能；除此之外首发候选代码未实现运营者服务器端个人数据收集。平台隐私保护指引要求，应以正式微信小程序后台的检测、配置和审核结果为准。不得假定不使用服务器就无需配置指引。

若未来加入云同步、注册登录、广告分析、社交、客服查看用户文字或支付，必须重新评估用户授权、数据去向、共享对象、保留与删除政策，先更新声明与配置再开放功能。

**规划说明**：微信/手机号登录、中国大陆云备份与管理员受限读取能力是已确定的未来功能，并非当前 v0.4 已启用；后续上线时必须在新版本上线前充分告知客服/审核必要读取等处理规则、完成适用法律依据、权限及安全评估，重新更新本隐私说明。详见 [长期产品规划](CN_CLOUD_ADMIN_ROADMAP.md)。
