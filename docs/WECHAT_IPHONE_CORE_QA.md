# 错事 · 微信 iPhone 首发核心功能验收 C01–C09

> **P0（首发阻断）**：需真人在正式候选构建的测试小程序上完成；开发者工具、Chrome 或模拟的文件 API 不能替代。
> 版本：以 Draft PR #5 `release/v0.4-rc1-prep` 最新固定源码 SHA、专用测试 AppID、微信与 iOS 版本为准。

## 测试前

使用有预览权限的**独立测试小程序**和虚构文字，最好是空白本地状态；不得清除任何真实私人记录。首发仍是纯本地版，没有云端找回。测试后需要保留合成数据可选择测试小程序专用 JSON 导出，但不要求完成微信聊天文件的反复恢复。

## 必过核心检查（不用走一整套 JSON 备份恢复）

| ID | 手动操作 | PASS 条件 |
| --- | --- | --- |
| C01 | 打开今天、日历、日期详情、统计、设置 | 页面均能正常进入，无白屏、明显错位、崩溃 |
| C02 | 今天从未记录开始，明确记录 0，再改成 2 | 未记录与明确 0 区分；数字输入、加减和撤销逻辑正确 |
| C03 | 在日历修改昨天为 1，再修改成 0 | 过去的数字、操作发生日期及修改前后历史正确；不写到今天 |
| C04 | 对今天添加、编辑并删除**虚构**简记 | 当前文字与事件历史可查，删掉简记不抹掉历史 |
| C05 | 看周/月/年统计，切换纸张/现代主题 | 统计包含明确 0 和过去的记录；主题返回后仍保留 |
| C06 | 将微信切后台再返回，并主动关闭小程序后重新打开 | 已确认保存的数字、简记和历史仍存在，日期与按钮状态正常 |
| C07 | 断网后再次修改测试数字或简记，恢复联网 | 无账号/网络时仍可本地保存，重新打开后结果一致 |
| C08 | 打开简记键盘、输入较长虚构文字，检查小屏/安全区、滚动和返回 | 文本不被键盘遮挡；按钮可点；无意外数据丢失 |
| C09 | 设置中点删除全部记录，先取消、再二次确认清空**仅测试数据** | 取消不删除；确认后本机记录与草稿清理状态如实显示；历史不假留 |

有一天发生跨午夜、DST 等边界时继续保留既有自动化断言；不要求本次人工等待跨午夜。**P0 的真实记录丢失、错误覆盖、异常上传/泄露、严重崩溃必须修复。**

完整 W01–W12 分享、聊天接收、文件选回、完整历史恢复测试见 [过渡专项](WECHAT_IPHONE_BACKUP_QA.md)。它**不再独立阻断首发**。现有功能仍须满足自动化安全约束和确认替换保护；发现可以使真实数据丢失或泄露的缺陷，必须修复或停用相关入口。

## 云端路线（后续 P1）

v0.5 账号、云端备份及跨设备同步必须保证**本机首次关联账号时安全迁移已有日期、简记和全量修改历史**；需要另外通过重试/冲突/断网、用户主动注销及服务端数据删除等验收。首发版不能声称已有云备份，清除微信小程序数据、卸载或更换设备仍可能无法找回本机数据。
