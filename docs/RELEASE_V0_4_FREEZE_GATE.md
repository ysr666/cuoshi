## 首发功能范围（仅冻结 v0.4；云备份与管理员为已确定的后续版本要求）

- 今天：未记录、明确 0、数字加减、数字输入、短暂撤销。
- 日历与日期详情：修改过去，查看所有历史事件及时间。
- 简记：完全可选，新增/编辑/删除不清除历史；未提交草稿只本机保留。
- 统计：周/月/年汇总；明确区分空白、0 和纯文字。
- 设置：纸张/现代两主题、隐私说明、JSON 完整备份导出与确认导入、二次确认删除。
- 无账户、无云端同步、无付费、无广告、无排行榜、无 AI 判断或惩罚性提醒。

> **长期路线不取消**：v0.5 起的账号、云备份、同步和客服/审核管理后台继续在原 [Draft PR #4](https://github.com/ysr666/cuoshi/pull/4) 开发；首发分支只放 v0.4 客户端和发布验收材料。

**本分支完全不含未来云服务代码。** 首发源码和编译包使用 `test:release:scope` 验证范围，不用“云服务还在代码里但没打包”作为发布隔离证明。详情见 `RELEASE_SCOPE_MANIFEST.md`。

3. 不上传用户 JSON 文件、明文简记或正式 AppSecret 到 GitHub、PR、日志、截图或第三方服务。
4. 该候选版本未开放任何公开上线权限；在线旧网页版不受本分支影响。
