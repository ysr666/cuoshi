## 首发功能范围（仅冻结 v0.4；云备份与管理员为已确定的后续版本要求）

- 今天：未记录、明确 0、数字加减、数字输入、短暂撤销。
- 日历与日期详情：修改过去，查看所有历史事件及时间。
- 简记：完全可选，新增/编辑/删除不清除历史；未提交草稿只本机保留。
- 统计：周/月/年汇总；明确区分空白、0 和纯文字。
- 设置：纸张/现代两主题、隐私说明、二次确认删除；保留已有 JSON 手动导出与确认导入作为**过渡辅助功能**，不把完整聊天恢复链路列为首发 P0。
- 无账户、无云端同步、无付费、无广告、无排行榜、无 AI 判断或惩罚性提醒。

> **长期路线优先级上调**：v0.5 起的账号、云备份、多设备同步及本地全历史安全迁移，是正式产品能力；客服/受限管理员后台按合规要求继续在原 [Draft PR #4](https://github.com/ysr666/cuoshi/pull/4) 独立研发。首发 v0.4 仍是无账号的本地版，**不能提前宣传“数据已上云”或“换机自动恢复”**。

**本分支完全不含未来云服务代码。** 首发源码和编译包使用 `test:release:scope` 验证范围，不用“云服务还在代码里但没打包”作为发布隔离证明。详情见 `RELEASE_SCOPE_MANIFEST.md`。

## 发布规则

1. 所有 P0 项目达到 PASS 才能创建明确对应一个 commit 的 RC tag，向微信正式审核上传；审核驳回后只能基于当前范围做必要修复并再次跑回归，不在首发阶段加新功能。
2. 需要正式注册人完成的身份、实名、备案操作不交给自动脚本，不以测试 AppID 替代正式 AppID。
3. 不上传用户 JSON 文件、明文简记或正式 AppSecret 到 GitHub、PR、日志、截图或第三方服务。
4. 该候选版本未开放任何公开上线权限；在线旧网页版不受本分支影响。
