## 给微信审核人员的功能说明（拟稿）

> 「错事」是个人备忘记录工具。打开首页即可为当前日期记录一个数字（0–9999），0 表示用户明确记为零，破折号表示尚未记录；点击数字可修改。用户可以添加不超过 300 字的可选简记。在日历中查看历史日期、修改过去的记录；日期详情保存操作时间、修改前后数字及简记历史。统计页面汇总记录。设置中可切换两套主题，也可导出 JSON 备份、主动导入替换记录或二次确认删除本机记录。产品不提供公开内容、社交互动、账号系统、支付、云同步或广告。

## 审核功能路径

1. 首次打开「今天」：点「＋」或「记为 0 件」，可点中央数字直接修改；点「−」减数。
2. 在「简记」输入文本后点「留下」；编辑、删除均保留历史。
3. 「日历」点过去日期进入详情，查看修改记录；「统计」查看周、月、年汇总。未来日期禁止编辑。
4. 「设置」切换纸张与现代两种主题。
5. 「设置」点「导出完整备份」，在微信的文件分享流程中手动选择聊天接收；点「导入备份」从微信聊天中选择 JSON 文件，经格式与校验检查、再次确认才替换本机记录。
6. 清空本机记录需二次确认。未提交简记草稿不包含在备份中。

## 隐私和平台接口核验

- 本地业务数据：数字、简记、修改前后文本、操作时间和时区、用户选的主题及草稿。默认本机保存。
- 备份明文 JSON 需要用户主动触发；分享进入微信聊天系统，用户决定接收者；导入仅读取用户主动选中的聊天文件。
- 主要微信接口：`wx.getStorageSync`/`setStorageSync`/`removeStorageSync`，`wx.getFileSystemManager`、`wx.shareFileMessage`、`wx.chooseMessageFile`，以及标准小程序页面导航/弹窗/提示能力。
- 正式隐私保护指引中的具体个人信息处理条目，**以新申请 AppID 后微信平台提供的接口核验清单为准**；草稿见 `docs/PRIVACY_NOTICE_DRAFT.md`。
- 不承诺“数据从未经过微信服务器”，因为用户主动分享文件时微信负责聊天传输。
