# 错事 v0.5 · 个人主体注册与备案实操路径

**主体已选择：个人（不是企业/组织）。状态：尚未提交任何实名或备案申请，未经官方平台审批；本文件不保存身份资料。**

## 重要时间前置

计划由本人使用合法真实身份办理。腾讯云中国站官方当前要求个人账号实名认证申请人**年满 18 周岁**（下列官方资料），不能用其他人的身份、域名或云账号替代真正运营主体。微信小程序个人主体的可注册条件、具体类目和认证步骤须在实际注册页面核实；不要把腾讯云的年龄规则未经核实套用于微信公众平台本身。

在满足平台注册条件之前，可以完成仓库内的发布检查、隐私草案、测试脚本与域名方案评估；**不提交身份证照片、不向 GitHub 上传个人手机号、家庭地址、实名核验信息或个人账号验证码。**

## 两条独立办理链路

**链路 A：微信小程序个人主体及小程序备案**

1. 打开 [微信公众平台](https://mp.weixin.qq.com/)，使用本人控制、符合平台规则的邮箱申请“小程序”账号，选择**个人主体**。完成平台要求的本人核验，不选企业主体。
2. 申请「错事」名称及符合个人主体开放范围的实际服务类目。类目由微信后台核定；如平台不允许某一类目，不能擅自写别的类目欺骗审核。记录官方申请结果（通过/驳回及原因，不公开个人证件信息）。
3. 登录小程序后台取得 AppID（这是客户端可见的公开应用标识，可用于构建），检查备案入口与后台要求；完成**小程序本身的备案**，等待平台/管局最终结果。微信小程序备案并不是给后端域名备案。
4. 备案完成后在正式候选包设置**可核实的小程序备案号**，按平台当前要求在小程序界面展示，并填写实名运营者可公开的隐私请求联系方式。`CUOSHI_V05_FILING_NUMBER` 专指这个可公开的、小程序实际获批的备案编号，不能填域名 ICP 号码冒充。

**链路 B：中国大陆云资源、HTTPS 接口域名**

1. 默认倾向腾讯云中国站，目的是减少跨服务商实名/备案流程；尚未获批准采购、没有选择或购买实例。也可以选择其他合规云商，届时改用对应服务商的 ICP 流程。
2. 如果选择腾讯云，先由本人完成个人实名认证，再在同一主体/账号下准备一个自己的可备案域名及符合备案条件的中国大陆云资源。域名实名持有人、ICP 主体和云接入信息应一致；腾讯云的个人实名不可先借用其他主体信息备案。
3. **后端请求域名的 ICP 备案/接入备案是与微信小程序备案不同的一条路径。** 腾讯云当前文档表明，国内云服务器对外提供服务的域名需在所属接入商办理备案，跨接入商迁移可能需接入备案。选择符合个人主体可使用的域名后缀，购买和是否需要保持至少 3 个月的备案服务器资源应按实际服务商当前控制台核实。
4. 备案及合法域名审核完成后配置 DNS/TLS/微信 request 合法域名；AppSecret 只保留于服务端，数据库至少使用四个受限角色；经真实 HTTPS 与双真机核验后才能将 `CUOSHI_V05_RELEASE_CANDIDATE=1` 用于正式候选构建。

## 用户现在需要本人完成的最短工作

- **现在（未到官方允许实名条件前）**：确认自己控制的注册邮箱、微信账号可正常登录、可用于公开接收个人信息请求的邮箱名称；先在微信平台核对“个人”能否使用当前类目、名称。暂不购买云资源，也不填虚构的备案号。
- **符合注册及实名条件后**：在微信公众平台注册**个人主体**，记录审核结果及 AppID；腾讯云如作为服务商，以**同一人**完成中国站个人实名认证；申请小程序备案及后端域名备案所需材料。
- **只需告诉工程侧**：个人主体注册是否成功、AppID（公开标识）、小程序备案是否批准、拟用云商、已批准的 HTTPS 域名与公开联系邮箱。**不要发送**身份证、证件照片、手机短信、人脸验证、AppSecret、数据库密码、云主账号密码或 JWT。
