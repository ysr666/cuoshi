# 错事 · uni-app 统一跨端工程 v0.4 Alpha.3

> 功能迁移中的可测试代码，不替换已上线的「错事」网页版。定位：**一个不对用户做道德评判的、安静的私人记录工具**。

## 多端结构

- **uni-app + Vue 3 + TypeScript**：使用相同的页面、领域模型和业务逻辑，分别构建 H5、微信小程序和 App；各端 API 适配不能省略。
- `src/core/model.ts`：无平台依赖的完整历史数据、数字记录/撤回/撤销、简记增删改和校验。
- `src/core/backup.ts`：纯 JavaScript SHA-256；导出旧网页版兼容的 JSON v2 校验备份；能导入未加密的旧 v0.3.1/v0.4 备份。
- `src/core/store.ts`：uni 本地存储适配；保存失败时不修改内存状态；检测并拒绝陈旧页面覆盖。**本层不保证跨进程原子事务，正式生产仍需平台特定的事务方案。**
- `src/platform/backupIO.ts`：H5 下载/文件选择，以及微信聊天会话选 JSON、分享备份文件；原生 App 文件选择尚未实现。
- `src/pages`：四个底部入口「今天、日历、统计、设置」，「日期详情」作为子页面。

## 本轮从 Alpha.1 补全的功能

1. 数字修改、显式零、未记录、撤回数字、12 秒轻量撤销（撤销本身保留事件）。
2. 简记编辑/删除；保留修改前的文字和时间戳。
3. 日历选择月份、返回本月、纯文字记录标识；日期详情的前后翻阅及全部历史。
4. 周/月/年统计、年度月份分布，未记录不视为零。
5. JSON 备份及 SHA-256 防篡改校验、导入前预览确认、清除全部记录的二次确认。
6. 纸张与文字 / 现代极简两种皮肤。

### 个人数据保护

当前 **v0.4** 版本无账号、无联网同步、无远程正文访问。数据只保存在当前应用的本地存储。后续云版本支持受限的客服和合法必要审核访问，不能将本地版的说明误用为云端版永久承诺。导出的普通 JSON 含有明文简记及修改历史，必须自己妥善保管。

**旧版迁移方式：** 从现有网页版设置页导出**普通 JSON 备份**，再在本工程的 H5 或微信小程序版导入。不同 origin、微信容器和原生 App 的本地存储隔离，不能自动静默迁移。新旧版共用 `version:1` 的记录事件格式，且会保留完整历史。`encryptedFormat:1`（现有 HTML v0.4 加密文件）暂不能在本工程直接解密，需先在旧版有密码的环境内解密后另存普通 JSON；切忌在不安全环境下处理私人数据。

### 已确定的后续功能（不属于 v0.4 首发）

- **确定要做**：微信授权登录、手机号验证码登录、账号绑定/注销，国内云备份与恢复，跨设备同步，以及合规客服/内容审核管理后台。详细阶段和权限边界见 [中国大陆云备份与管理员规划](docs/CN_CLOUD_ADMIN_ROADMAP.md)。
- 用户自主选择开启云同步；首次启用前明确告知并取得适用授权，不应擅自上传已有本地记录。
- 正文由有权限的客服（用户工单）、内容安全审核员（依法明确的审核目的）按需读取，建立分角色权限、访问理由、访问审计、留存和删除机制；**不宣传运营者无法阅读云端正文**。
- 单独的中国大陆后端项目及相应备案、隐私政策、用户协议、未成年人保护和数据安全评估；现有境外 Supabase TripMap 项目不存储真实「错事」用户数据。
- 不上架、不开启真实微信/手机登录，也不开始采集真实云端数据，直至安全与合规完成。

## 测试

当前环境中验证过：

```bash
npm run test:core    # 旧 16 项模型断言
npm run test:v04     # 新 48 项模型/备份/校验断言
npm run test:store   # 30 项模拟 uni 本地存储、冲突和失败回归
```

三套共 **94 项断言**；只是纯 JS/TS 及模拟 uni 环境的测试，不等于通过微信开发者工具、Safari 或 App 真机测试。

## 编译、微信开发者工具与正式账号准备

1. 在可以访问 npm 的环境中安装与当前官方模板匹配的同版本 `@dcloudio/*` 依赖并锁定版本：`npm install`。
2. `npm run dev:h5` / `npm run build:h5`。
3. 在 `src/manifest.json` 的 `mp-weixin.appid` 填入**你自己小程序**的真实 AppID，执行 `npm run dev:mp-weixin` 或 `npm run build:mp-weixin`。
4. 微信开发者工具打开产物目录，完成微信正式基础库、独立包、扫码真机预览、离线与文件分享验收。
5. Android/iOS 原生版本需要额外构建流程和文件 IO 适配，当前未达到发布条件。

> 截至 2026-10-16：Mac 上的 TypeScript、94 项核心断言、H5/微信双端编译、H5 Chrome 回归、微信开发者工具独立预览工程的基础页面/历史模拟器检查均已执行。微信 iPhone **真实文件分享/导入恢复仍待人工验收**，代码尚未合并或公开发布。详见 `DEVELOPMENT_STATUS.md` 以及 `docs/RELEASE_V0_4_FREEZE_GATE.md`。旧网页版仍保持不变。

## 设计原则

不做错误识别、AI 说教、情绪评分、排行榜、连续打卡或强制每日提醒。允许用户重新判断过去的数量，并保留全部旧判断。隐私默认本地、操作安静且可恢复。
